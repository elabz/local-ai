## ADDED Requirements

### Requirement: Topology tables are generated from the manifest
The model table and the PEA port-layout table in CLAUDE.md SHALL be generated by `render-config.py` from `gpu-server/models.yaml`, and SHALL live between explicit BEGIN/END GENERATED markers. Text outside the markers SHALL NOT be modified by the generator.

#### Scenario: Manifest change updates the docs
- **WHEN** a replica is added to or removed from a model group in `models.yaml` and `render-config.py` runs
- **THEN** the CLAUDE.md model and port tables reflect the new replica set, and the prose outside the markers is byte-identical

### Requirement: CI fails on documentation drift
`render-config.py --check` SHALL fail when the generated CLAUDE.md block differs from what the manifest would produce.

#### Scenario: Hand-edited table
- **WHEN** someone hand-edits a row inside the generated block without changing `models.yaml`
- **THEN** the model-manifest CI job fails and names CLAUDE.md as drifted
